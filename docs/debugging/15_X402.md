## 1. Protocol Implementation

The Workline x402 module implements machine-to-machine service monetization over the Algorand testnet/mainnet:
1. Client requests an engineering service via `/api/x402/execute/{service_id}`.
2. Gateway returns `HTTP 402 Payment Required` with `X-Payment-Required` challenge header containing nonce, asset ID, price, and receiver address.
3. Client submits transaction proof in `X-PAYMENT` header.
4. `X402Verifier` confirms transaction validity on-chain or via GoPlausible facilitator before unlocking service execution.

## 2. Service Catalog & Endpoints

- `GET /api/x402/services`: Returns list of payable services (e.g. PCB DRC Analysis, Thermal Simulation, DFM Sourcing). Status: `200 OK`.
- `GET /api/x402/payments`: Audit log of settled micropayments. Status: `200 OK`.
